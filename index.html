Utiliti Eksport & Import Data 1-ke-1 (JSON)

Pindahkan atau pulihkan keseluruhan rekod aktiviti dalam format fail tunggal .json.

Langkah 1

Eksport Sandaran JSON

Muat turun semua rekod daripada pangkalan data semasa berserta definisi lajur dan kunci utama tanpa had tapisan.

Langkah 2

Import & Pulih Skema

Pilih fail sandaran .json untuk mengesahkan skema dan memulihkan rekod ke jadual aktiviti.

Panduan Ringkas Migrasi 1-ke-1:

1. Klik Profil Pelayan dan masukkan URL, Kunci Anon serta skema asal (rekod_aktiviti), log masuk admin, kemudian klik Muat Turun Sandaran (.json).

2. Klik Profil Pelayan semula dan pilih Guna Konfigurasi Asal (skema pap pada Supabase baharu), log masuk admin baharu, dan muat naik fail .json tersebut.
